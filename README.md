# Calculadora de Números Gigantes em C

Este projeto implementa uma calculadora capaz de realizar operações matemáticas com números inteiros de tamanho arbitrário, utilizando a linguagem C.

## 📌 Sobre o projeto

A calculadora realiza operações sem depender dos tipos numéricos primitivos do C, utilizando strings para representar os números e simular o cálculo manual realizado no papel (dígito por dígito).

Este é o meu primeiro projeto desenvolvido na disciplina de Fundamentos de Programação, no início da minha formação acadêmica, com foco no desenvolvimento de lógica de programação, manipulação de strings e compreensão de algoritmos básicos.

## ⚙️ Operações implementadas

- Soma
- Subtração
- Multiplicação
- Exponenciação
- Fatorial

## 🧠 Como funciona

As operações são realizadas simulando o processo manual:

- Soma: dígito por dígito com controle de vai-um
- Subtração: dígito por dígito com empréstimo
- Multiplicação: simulação da multiplicação tradicional
- Exponenciação: multiplicações sucessivas
- Fatorial: multiplicações sucessivas de 1 até n
